# 📚 Gerenciador de Biblioteca Pessoal

Um projeto desenvolvido em Python para gerenciar uma biblioteca pessoal por meio de um menu interativo no terminal.

## Funcionalidades

- Cadastrar livros com título, autor, ano e categoria.
- Validar os dados informados durante o cadastro.
- Listar todos os livros cadastrados.
- Pesquisar livros pelo título.
- Atualizar o status de leitura dos livros.
- Remover livros da biblioteca.
- Exibir estatísticas da biblioteca, incluindo:
  - Total de livros cadastrados.
  - Livros não iniciados.
  - Livros em andamento.
  - Livros concluídos.
- Validar as opções informadas no menu.
- Informar quando a biblioteca estiver vazia.
- Encerrar o programa pelo menu.

## Tecnologias utilizadas

- Python 3
- Listas e dicionários
- Funções
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`for` e `while`)
- Entrada e saída de dados (`input` e `print`)
- Métodos de strings (`strip`, `lower` e `isdigit`)

## Como executar

1. Tenha o Python instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python main.py
```
