# 📚 Gerenciador de Biblioteca Pessoal

Um projeto desenvolvido em Python para cadastrar e listar livros de uma biblioteca pessoal por meio de um menu interativo no terminal.

## Funcionalidades

- Cadastrar livros.
- Listar livros cadastrados.
- Exibir título, autor, ano, categoria e status de leitura.
- Informar quando a biblioteca estiver vazia.
- Validar opções do menu.
- Encerrar o programa pelo menu.

## Tecnologias utilizadas

- Python 3
- Listas e dicionários
- Funções
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`for` e `while`)
- Entrada e saída de dados (`input` e `print`)

## Como executar

1. Tenha o Python instalado.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
python main.py
```
